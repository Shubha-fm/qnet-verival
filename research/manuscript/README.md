# Final ACM manuscript

Extract a ZIP and select main.tex. The official acmart class and its original source/license are included. Standard font dependencies require a full TeX Live or Overleaf installation.

The public variant includes verified repository and pinned base/extension revisions. The review source and PDF omit author-identifying repository links. A separate complete anonymous supplementary artifact is supplied with the manuscript deliverables. The author block remains anonymous; no author identities were inferred.

Both versions compile without undefined references or overfull boxes. No claim is made that inaccessible journal-specific review instructions have been fully verified.
